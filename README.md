# Daylight — holiday planner

A personal holiday calendar for keeping holidays, plans, and trips together.

## Run it

Open `index.html` in a browser. No install or build step is needed.

Use the arrows to browse months, select a date on the calendar, and add an event with its type and an optional note. Events and your dark-mode preference are saved in this browser using local storage.

The calendar is preloaded with India-wide national holidays and major festivals for 2026 and 2027, the supplied Thaurprasad dates for 2027, and selected Karnataka observances for 2026 and 2027. Festival dates follow the [Drik Panchang Indian festival calendar](https://www.drikpanchang.com/calendars/indian/indiancalendar.html); observances can differ by region, and lunar dates may shift with local moon sightings. Karnataka's state holiday notification may differ, so confirm official dates before making plans. This is a broad personal-planning calendar, not a complete list of every state or employer's holidays.
